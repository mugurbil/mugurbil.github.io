Mehmet Ugurbil

I work on making large models run on data nobody has to reveal, at the intersection of machine learning and cryptography.

Google Scholar GitHub IACR ePrint

SF Bay Area

I build machine learning systems at Google. My research is on privacy-preserving machine learning: secure multi-party computation (MPC) and fully homomorphic encryption (FHE) that are fast enough to run modern models, LLMs included.

A recurring idea in my work is using wavelet approximations to make non-linear functions cheap under encryption. It started with programmable bootstrapping for FHE, went into mixed-mode MPC, and then into private LLM inference. Before that I worked on Markov chain Monte Carlo for Bayesian inverse problems, clinical risk prediction, and MRI reconstruction.
