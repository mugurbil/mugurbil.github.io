Mehmet Ugurbil

Machine Learning Engineer · Google · SF Bay Area

Scholar GitHub IACR ePrint

I build machine learning systems at Google. My research sits where machine learning meets cryptography: making large models run on data nobody has to reveal, using secure multi-party computation (MPC) and fully homomorphic encryption (FHE).

A recurring idea in my work is using wavelet approximations to make non-linear functions cheap under encryption. It started with programmable bootstrapping for FHE (Ripple), then went into mixed-mode MPC (Wave Hello), and then into private LLM inference (Curl, Fission). Before that I worked on Markov chain Monte Carlo for Bayesian inverse problems, health informatics, and MRI reconstruction.
